    # AI Impact Monitor
    **AI Impact Monitor** is a Chrome Extension (Manifest V3) designed to track the environmental footprint of AI usage in real-time. It monitors prompt frequency across major platforms like **ChatGPT, Claude, Gemini, and Perplexity**, providing users with instant feedback on their CO2 emissions, energy consumption, and water usage.

    ## Features
    - Multi-Platform Support: Automatically detects activity on ChatGPT, Claude, Gemini, and Perplexity.

    - Environmental Analytics: Calculates estimated CO2 (grams), Energy (Wh), and Water (Liters) based on prompt metadata, using 2026 industry-standard benchmarks.

    ## Privacy-First Design:

    - No personal text or chat history is ever collected.

    - Data sharing for research is opt-in only.

    - Onboarding screen ensures users understand data usage before tracking begins.

    - Historical Trends: Visualizes daily, weekly, and monthly usage via CSS-based graphs.

    - Relatable Comparisons: Converts abstract metrics into real-world examples (e.g., "equivalent to charging your phone 5 times").

    ## Technical Architecture
    ### Core Components
    - Content Scripts (main.js): Monitors the DOM of AI platforms to detect successful prompt submissions.

    - Background Service Worker (background.js): The engine of the extension. Manages session logic, ID generation (User/Session), and secure API communication with the backend.

    - Popup UI (popup.html/js): A Bundled dashboard showing personal stats and the onboarding/opt-in flow.

    - Storage: Utilizes `chrome.storage.local` for persistence, ensuring data survives browser restarts.

    ### Data Flow
    - **Detection**: Content script identifies a prompt event.

    - **Logic**: Background script validates session state and checks data_sharing permissions.

    - **Storage**: Local usage stats are updated regardless of sharing status.

    - **Research Sync**: If opted-in, anonymized metadata is sent to https://ai-monitor.madebyshu.net/events.

    ## Installation & Development

    ### Prerequisites
    Node.js (v18+)

    npm or yarn

    ### Setup

    Clone the repository:
    Bash
    `git clone https://github.com/Sjoerd473/AI_monitor_plugin`
    `cd ai-impact-monitor`

    Install dependencies:
    Bash
    `npm install`

    Build the project:
    Bash
    `npx vite build`

    ### Loading into Chrome
    Open Chrome and navigate to `chrome://extensions/`.

    Enable Developer mode (top right).

    Click Load unpacked and select the `dist` (or `build`) folder generated by the `build` command.

    ## Privacy & Transparency
    We take privacy seriously. The extension follows a "Privacy by Design" framework:

    - **Zero Text Logging**: We do not read or transmit the content of your prompts.

    - **Anonymization**: User IDs are generated locally using crypto.getRandomValues and are never linked to your Google or AI platform accounts.

    - **Disclosure**: Users are presented with a "First Run" screen to toggle data sharing preferences.

    ## Comparison Metrics
    The extension uses the following approximations for environmental impact:

    - **CO2**: Based on global average grid intensity per inference.

    - **Energy**: Estimated Wh per prompt including data center cooling overhead.

    - **Water**: Estimated ML used for cooling per inference cycle.
